- ASOS/AWOS METAR winds/gusts/MSLP; exact ASOS NOAA/IEM minute archive for documented two-minute winds, five-second maxima and completely tiled minute precipitation. Station pressure/altimeter readings are not converted into MSLP.
- NDBC recent and annual standard-meteorological winds/gusts/pressure, verified header units and per-variable peaks. Conflicting overlapping-feed timestamps are withheld.
- CO-OPS levels explicitly requested relative to MHHW and checked against NOAA datum metadata; USGS direct NAVD88 series using independently checked official parameter definitions for 63160/62620/62615. Parameter62020 is excluded because it describes albuterol.
- Exact linked WeatherSTEM historical sensors and original-unit provenance; gusts supported, sustained/pressure only with explicit averaging/MSLP identity. Historical POST parameters are retained for reproduction.
- Credentialed Synoptic/MesoWest exact-ID wind/gust/MSLP retrieval. Unqualified speed peaks stay in QC rather than being represented as sustained winds. Inconsistent concurrent gust/speed records are quarantined.
- Official exact-station CoCoRaHS and Synoptic precipitation queries, with complete interval/unit/identity gates. A query is not counted as a successfully populated total when its semantics are insufficient.
- RiverGages metadata and historical HML stage retrieval for original USACE/CPRA identifiers. **19 development and 20 historical stage series were retrieved**, with unconverted peaks/UTC/source in QC. No stage is relabelled NAVD88 or inundation. Independently reviewed station/event-effective registries enable conversions; none are supplied or self-approved.

- Native top-ten tables, source/QC/provenance tabs, review and candidate CSVs, manifested ZIP/XLSX downloads, dashboard filtering and reviewed WeatherFlow JSON staging/import. Imports validate the whole batch and replace active provenance while preserving superseded observations.
- GitHub Actions tests, builds, validates workbook/CSV/dashboard/download consistency, uploads artifacts and deploys Pages. Owner-confirmed `SYNOPTIC_TOKEN` and `USGS_API_KEY` are configured; credentials are absent from exports.

## Unavailable, conditional or manual fields

WeatherFlow is the only intentionally excluded automatic network. Its28 station metadata rows remain, with reviewed manual entry available. Other gaps result from unavailable records or failed scientific qualification:

| Source/field | Specific limitation and resulting behavior |
|---|---|
| CoCoRaHS rainfall | Live public responses lack accumulation duration (`numDays`) and have unresolved UTC/local-clock semantics. No complete storm total is inferred from matching daily sums. All 129 queried template rows remain incomplete in both cases. |
| Synoptic/COOP/HADS/RAWS rainfall | Endpoint/count aggregates do not prove interior accumulation coverage. Explicit contiguous intervals are required; current aggregate responses are withheld. Exact-ID rejections/access failures remain visible in QC. |
| ASOS/AWOS rainfall | Missing/trace intervals, archive lag and unsupported routine-METAR accumulation boundaries remain incomplete. The development interval ends2026-10-10 00:00 UTC, beyond this run's generation time; complete storm rain is unavailable. |
| USACE/CPRA elevations | Historical stage can be retrieved, but current gage-zero text does not establish an independent event-effective conversion. No approved registry exists. Ambiguous identifiers are not mapped to HML silently. Native RiverGages historical-chart ingestion is not validated; HML is the implemented historical route. |
| USGS additional fields | Stage 00065 has no inferred offset. Rainfall is not represented by USGS rows in the rain inventory; unverified rain/wind series semantics are not mapped across tabs. Nonqualifying/missing direct NAVD88 series stay blank. |
| WeatherSTEM other fields | Averaging/MSLP metadata, counter/reset semantics, historical sensor changes and absence of WeatherSTEM rows in the rain inventory limit additional fields. No station or rainfall row is invented. |
| Generic Synoptic sustained speed | Explicit 1/2/8/10-minute averaging metadata required. Source speed peaks/time remain in QC when unavailable. |
| NDBC scope | Standard-met and recent/annual files are supported; monthly-only and higher-cadence continuous-wind products are not validated/implemented. Sampling differences can miss independently verified extremes. Upstream CloudFront 403 occurred in this cloud instance, although the Actions runner retrieved annual records. |
| TPCG | Template source links/archive mapping are absent; metadata is preserved and values remain unsupported. |
| Tornado completeness/impacts | Archive publication lag and textual attribution limit tornado completeness. No verified storm-specific impact narratives/fatality/injury/evacuation series are supplied; sample narratives/counts are cleared and human review is required. |
| Official issuance metadata | Development storm label/dates do not identify a real 2026 Isaias cyclone. Official ATCF identification, final product filenames/issuance and meteorologist decisions remain outside this review publication. |

All existing PSH tabs are retained. Candidate column counts and threshold filters follow NWSI 10-601 (August 17, 2026): gust>33 kt or MSLP<1005 mb, rain>=3 in; unsupported fields stay blank. Lower readings remain in review exports. Duplicate identifiers are flagged and excluded from CSVs. Candidate files require review before operational formatting/issuance.
